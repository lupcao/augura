Честно по замыслу: безопасный генератор случайных чисел твоего браузера, без смещения. Ничто не покидает эту страницу.

    Augura для iPhone

    Всё это и ещё 20 оракульных традиций, игры для компании, виджеты, Пункт управления и Apple Watch.

    Скоро

    Как это работает

    • Каждый уровень выпадает так же часто, как в обычном храмовом ящике: великая удача 18 раз из 100, великая неудача 3 раза из 100.
    • Честно: каждый результат берётся из безопасного генератора случайных чисел твоего браузера (crypto.getRandomValues), без смещения.
    • Приватно: ничто из введённого или вытянутого тобой не покидает эту страницу. Без cookie, без слежки.
