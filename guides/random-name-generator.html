Random name picker and name generator

Draw one to ten random first, last or full names from seven countries or from made-up fantasy, sci-fi and place-name sets. This page has a free browser tool at the top and a guide to the Name mode in the Augura iPhone app. The browser tool is simpler than the app mode: there is no web version of the full mode.

Pick names from your own list

Type or paste names, one per line, choose how many to pick and press Pick. This browser tool picks from your list: it does not invent names (the app's Name mode, described further down, does that).

What this tool does

  • Every line has the same chance, a line is never picked twice in one go, and the names are shown in the order they were drawn. A name you type twice counts as two lines.
  • Up to 200 names of up to 80 characters each. Blank lines are ignored.
  • Everything runs in this page on your device with the browser's secure random generator. No request is sent after the page loads, no account is needed and nothing is saved: closing or reloading the tab clears it.

What it is

Name picks random names from lists of common names. There is a list for the United States, the United Kingdom, Germany, Italy, France, Spain and Japan, each with about a hundred first names (female, male and unisex) and about a hundred family names. Japanese names are written family name first, in Latin letters.

Three made-up sets build names from syllables instead of lists: Fantasy (Aelwen Stormblade), Sci-fi (Zarix Vortek) and Place names (Oakford, Silverbury). The made-up sets can give a name nobody has used before, but one may also look a little like a real word.

How to use it

  • Names from (in the settings) chooses the country or made-up set. Changing it clears the current names.
  • Gender (Any, Female, Male) appears for the country lists. Unisex names are included with both Female and Male.
  • First, Last, Full chooses which part of the name to draw. Place names have no last name, so they only give one name.
  • How many draws 1 to 10 names at once, different from each other.

Tap Pick a Name, or shake your phone. The names shuffle for a moment and then settle.

Ideas

  • Name a character in a story or a tabletop game with a fantasy or sci-fi name.
  • Get a cast of ten names for a school exercise or a quiz.
  • Pick a name for a pet, a plant or a boat.
  • Invent a town for a map, a game or a writing prompt.

Widgets and shortcuts

Add a Name widget to your Home Screen and tap its button to draw a name without opening the app. Widgets use the set, gender and number of names you chose in the settings.

To reach Name by voice, add the Roll action in the Shortcuts app, set it to Name, and give the shortcut a name you can say to Siri. Draws from widgets and shortcuts go into your history.

How the draw works

Every name in the chosen list is equally likely. With a list of 100 first names, each has a 1 in 100 chance. First and last names are drawn separately, so a full name is a first name and a family name with no link between them. Common family names are not more likely here than rare ones: the lists hold common names, but each entry has the same chance.

Made-up names are put together from a start, sometimes a middle, and an end, each picked at random from its own table. Because of that, many different names are possible, and the same name can come up again.

Name lists are only a sample of the names people have. They are not complete, and they do not say how common each name is in real life.

Where it comes from

The country lists are a sample of common first and family names that ship inside the app; they are not complete. The three made-up sets are built from syllables by the app.

What it cannot do

  • It is not built as a baby-name, company-name or username tool: it draws from fixed lists and syllable sets.
  • It does not say how common a name is. Every entry in a list has the same chance.
  • A made-up name can look like a real word or a real person. Check it before you use it for anything important.
  • The app's Name mode does not pick from names you type yourself. The browser tool at the top of this page does, and so does the decision wheel.
