Random password, PIN and passphrase generator

Make a random passphrase, PIN, password or UUID with your browser's secure random generator, or with the iPhone app's Codes mode. This page has a free browser tool at the top and a guide to the Codes mode in the Augura iPhone app (coming soon to the App Store). The browser tool is simpler than the app mode: there is no web version of the full mode.

Make a code here

Choose the kind of code and its length, then press Generate. Nothing you generate leaves this page: it is made in your browser and no request is sent after the page has loaded.

What this tool does

  • Passphrase: 4 to 64 words, each one of 7,776 words from the EFF Large Wordlist (Electronic Frontier Foundation, CC BY 3.0 US), picked independently and joined with hyphens (four of the words, such as t-shirt, contain a hyphen themselves). PIN: 4 to 64 digits, each 0 to 9, and it may start with 0. Password: 4 to 64 characters, each one of 71 (letters without the look-alikes I, O and l, the digits 2 to 9 and the symbols - . _ ~ ! @ # $ % ^ & * + =). UUID: the standard random (version 4) format in lower case.
  • The code is made when you press Generate and shown only in the box below. It is not added to any list, and Clear removes it from the page. Closing or reloading the tab removes it too. There is no copy button: select the text yourself and copy it if you choose.
  • It does not rate a code, check it against data breaches or know the rules of the account you use it for. This page is not a password manager.
  • Everything runs in this page on your device with the browser's secure random generator. No request is sent after the page loads, no account is needed and nothing is saved: closing or reloading the tab clears it.

What it is

Choose a passphrase made from words, a numeric PIN, a password from the shown character set, or a UUID. The generator uses the system secure random generator and samples each available word, digit, or character evenly. This is a convenience tool, not a promise that a particular choice is suitable for every security policy.

How to use it

  1. Choose a code. Choose a passphrase, PIN, password, or UUID. The system secure random generator picks the result before it appears.
  2. Set a length. Set the number of words for a passphrase, or the number of digits or characters for a PIN or password. A UUID has its standard fixed format.
KindLengthWhat it is made of
Passphrase4 to 64 wordsEach word is one of 7,776 words (the EFF Large Wordlist), picked independently and joined with hyphens.
PIN4 to 64 digitsEach digit is 0 to 9, equally likely; a PIN may start with 0.
Password4 to 64 charactersEach character comes from a set of 71: letters without the look-alikes I, O and l, the digits 2 to 9 and the symbols - . _ ~ ! @ # $ % ^ & * + =.
UUIDfixedThe standard 36-character format, in lower case.

For scale only, with no claim about strength: a four-word passphrase is one of 3,656,158,440,062,976 possible combinations, and a four-digit PIN is one of 10,000. What is suitable depends on the account and on who might try to guess the code.

Where the code goes

In the browser tool the code stays in the box on this page: it is not sent, saved or added to a list, and Clear or closing the tab removes it. In the app:

A generated code stays on screen. Augura does not automatically put it in history, widgets, notifications, or logs. Use Copy or Share only when you choose, and treat the copied or shared value according to the privacy of the destination.

Where it comes from

Passphrases use the EFF Large Wordlist: 7,776 words chosen independently and joined with hyphens. The list is used only for passphrases. Credit: EFF Large Wordlist, Electronic Frontier Foundation, CC BY 3.0 US.

What it cannot do

  • It does not rate how strong a code is, check it against data breaches or store it. It is not a password manager.
  • It cannot know the rules of the account you are making a code for. Check that site's or device's own requirements.
  • The illustration above is printed on a public page: never use it. A code you make with the tool is shown only to you and is not saved.
